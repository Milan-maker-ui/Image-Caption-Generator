# Image-Caption-Generator
🚀 Built an AI Image Caption Generator using CNN + LSTM

✨ Features:
Generate AI-based image captions,
Deep Learning based CNN + LSTM model,
Text-to-Speech support,
Modern Flask web interface,
Real-time prediction,
Save trained model and tokenizer,
Production-ready project structure.

🛠 Tech Stack:
TensorFlow, Flask, Python, CNN, LSTM.

Dataset:
This project uses the Flickr8k dataset.
Download from:
Kaggle Flickr8k Dataset.
